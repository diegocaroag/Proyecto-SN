WEBLAB 2.0 - PROYECTO DIDÁCTICO
===============================

Objetivo:
Mantener la estructura original de WebLab y mejorar su presentación visual para acercarla a un prototipo elaborado en Figma, sin frameworks.

Flujo principal:
index.html -> login.html -> dashboard.html -> HTML / CSS / JavaScript / Formulario

Credenciales de práctica:
Correo: aprendiz@weblab.com
Contraseña: sena2026

Cambios principales:
1. Se mantiene la estructura y contenidos didácticos originales.
2. Se actualiza la estética general con tarjetas, mejor espaciado, layout responsive y navegación tipo dashboard.
3. Se agregan imágenes temporales en la carpeta img/ para que cada equipo pueda reemplazarlas por las de su proyecto.
4. Se agrega formulario.html como práctica independiente de formularios y validación.
5. El formulario NO implementa CRUD ni almacenamiento; únicamente valida y confirma un registro correcto.
6. No se incluye el atributo edad. Se utiliza fecha de nacimiento como dato de entrada.
7. La contraseña se solicita dos veces y debe coincidir.
8. Se elimina el acceso al Home desde el menú del Dashboard.

Formulario de práctica:
Incluye controles de tipo text, date, tel, email, password, select, radio y checkbox.
Valida nombre, fecha, documento, teléfono, correo, programa, contraseña segura, confirmación de contraseña, género y aceptación de términos.

Imágenes temporales:
- img/logo-placeholder.svg
- img/hero-placeholder.svg
- img/login-placeholder.svg

Para personalizar el proyecto, los equipos pueden reemplazar estos archivos conservando el mismo nombre, o modificar las rutas src en los archivos HTML.

IMPORTANTE:
El login es una SIMULACIÓN didáctica realizada en JavaScript y localStorage.
No representa una autenticación segura ni debe utilizarse como modelo de seguridad para producción.

Estructura:
- index.html: Home, carrusel y formulario de contacto.
- login.html: formulario de acceso y validación.
- dashboard.html: panel principal.
- formulario.html: formulario de registro con validaciones.
- html.html: material HTML5.
- css.html: material CSS3.
- javascript.html: material JavaScript.
- css/estilos.css: estilos de todo el proyecto.
- js/home.js: carrusel y validación de contacto.
- js/login.js: login simulado.
- js/dashboard.js: sesión simulada y cierre de sesión.
- js/formulario.js: validaciones del formulario de registro.
- img/: imágenes del proyecto.
