CSS3

CSS controla cómo se ve y cómo se distribuye el contenido HTML.

1. ¿Qué es CSS?

CSS (Cascading Style Sheets) describe cómo se presentan los elementos HTML: colores, tamaños, espacios, posiciones y adaptación a distintos dispositivos.

selector {
  propiedad: valor;
}

2. Formas de aplicar estilos

En línea

<p style="color: blue;">Texto</p>

Interno

<style>
  p { color: blue; }
</style>

Externo — recomendado para el proyecto

<link rel="stylesheet" href="css/estilos.css">
Recomendación: utilizar archivos CSS externos facilita mantenimiento, reutilización y separación de responsabilidades.

4. Clases

Una clase CSS es una forma de reutilizar un conjunto de estilos en varios elementos HTML.

/* CSS */
.boton {
  padding: 10px 16px;
  border-radius: 6px;
}

/* HTML */
<a class="boton" href="login.html">Ingresar</a>
<button class="boton" type="submit">Guardar</button>

El mismo elemento puede combinar clases: class="boton boton-secundario". Esto permite crear una clase base y variaciones.

5. Cascada, herencia y especificidad

Cascada: CSS decide qué regla prevalece cuando varias afectan al mismo elemento. Herencia: algunas propiedades, como el color o la fuente, pueden heredarse de un elemento padre. Especificidad: reglas más específicas pueden prevalecer sobre otras menos específicas.

p { color: black; }       /* elemento */
.aviso { color: orange; } /* clase: más específica */
#urgente { color: red; }  /* id: aún más específica */

6. Colores, tipografía y unidades

Se pueden usar colores por nombre, hexadecimal, rgb() o hsl(). Para tamaños son comunes px, rem, %, vw y vh.

body {
  font-family: Arial, sans-serif;
  font-size: 1rem;
  line-height: 1.6;
}
h1 { font-size: 2.2rem; }

7. Modelo de caja

Todo elemento se representa como una caja formada por contenido → padding → borde → margen.

.tarjeta {
  width: 300px;
  padding: 20px;
  border: 1px solid #ccc;
  margin: 16px;
  box-sizing: border-box;
}

8. Display, Flexbox y Grid

display determina cómo participa un elemento en la distribución. Flexbox funciona muy bien para distribuir elementos en una dimensión; Grid para estructuras de filas y columnas.

.menu {
  display: flex;
  gap: 1rem;
  align-items: center;
}
.tarjetas {
  display: grid;
  grid-template-columns: repeat(3, 1fr);
  gap: 1rem;
}

9. Diseño responsive

Las media queries permiten cambiar reglas según las características de la pantalla.

@media (max-width: 768px) {
  .tarjetas {
    grid-template-columns: 1fr;
  }
}

También son importantes el meta viewport, anchos flexibles e imágenes con max-width: 100%.

10. Estados y transiciones

.boton {
  transition: transform .2s;
}
.boton:hover {
  transform: translateY(-2px);
}

Pseudoclases como :hover, :focus y :disabled permiten representar estados de interacción.

11. Buenas prácticas

  • Preferir clases reutilizables frente a estilos en línea.
  • Usar nombres de clases comprensibles.
  • Evitar repetir reglas innecesariamente.
  • No depender solo del color para comunicar información.
  • Mantener suficiente contraste y foco visible.
  • Diseñar pensando también en pantallas pequeñas.

12. Errores frecuentes

  • Olvidar el punto en un selector de clase.
  • Confundir margin con padding.
  • Usar demasiados !important.
  • Asignar tamaños rígidos que rompen la página en móvil.
  • Duplicar estilos en muchos elementos en lugar de crear una clase.
