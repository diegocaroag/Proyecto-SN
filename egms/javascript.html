JavaScript

JavaScript agrega lógica, eventos e interacción al documento HTML.

1. ¿Qué es JavaScript?

JavaScript es un lenguaje de programación que permite agregar lógica e interacción a una página: responder a clics, validar formularios, modificar contenido y trabajar con datos.

<script src="js/app.js"></script>

En este proyecto los scripts se ubican al final del body para que el HTML esté disponible antes de ejecutar el código.

2. Variables y constantes

let contador = 0;
const nombreCurso = "JavaScript";

let declara una variable cuyo valor puede cambiar. const declara una referencia que no se reasigna. Para código moderno se prefieren sobre var.

3. Tipos de datos básicos

  • string: texto.
  • number: números.
  • boolean: true o false.
  • null: ausencia intencional de valor.
  • undefined: valor no definido.
  • object: colección estructurada de datos.
  • array: lista de valores.
const aprendiz = {
  nombre: "Ana",
  activo: true
};
const temas = ["HTML", "CSS", "JavaScript"];

4. Operadores

Hay operadores aritméticos (+ - * / %), comparación (=== !== > < >= <=) y lógicos (&& || !).

const edad = 20;
const puedeIngresar = edad >= 18 && edad < 100;

5. Condicionales

if (nota >= 70) {
  console.log("Aprobado");
} else {
  console.log("Debe reforzar");
}

También existe switch para seleccionar entre varios casos claramente definidos.

6. Ciclos

const temas = ["HTML", "CSS", "JS"];
for (const tema of temas) {
  console.log(tema);
}

for, while y métodos de arreglos permiten repetir operaciones. Deben utilizarse cuando realmente existe una colección o repetición.

7. Funciones

Una función agrupa instrucciones reutilizables y puede recibir parámetros y devolver un resultado.

function calcularSubtotal(cantidad, precio) {
  return cantidad * precio;
}
const subtotal = calcularSubtotal(3, 25000);

También existen funciones flecha:

const saludar = nombre => `Hola, ${nombre}`;

8. DOM: conectar JavaScript con HTML

El DOM (Document Object Model) representa el documento HTML como objetos que JavaScript puede consultar y modificar.

const titulo = document.querySelector("#titulo");
titulo.textContent = "Nuevo título";
titulo.classList.add("destacado");

Selectores frecuentes: getElementById(), querySelector() y querySelectorAll().

9. Eventos

Un evento informa que ocurrió una acción, por ejemplo un clic, una escritura o el envío de un formulario.

const boton = document.querySelector("#guardar");
boton.addEventListener("click", function () {
  alert("Guardado");
});

Eventos frecuentes: click, submit, input, change, keydown.

10. Formularios y validación

const formulario = document.querySelector("#registro");

formulario.addEventListener("submit", function (evento) {
  evento.preventDefault();

  const nombre = document.querySelector("#nombre").value.trim();

  if (nombre.length < 3) {
    mostrarError("El nombre debe tener mínimo 3 caracteres");
    return;
  }

  console.log("Formulario válido");
});

preventDefault() evita temporalmente el comportamiento normal del envío para poder validar. JavaScript complementa, no reemplaza, las validaciones HTML ni la validación que posteriormente debe realizar un servidor.

11. Manipulación de clases

const menu = document.querySelector(".menu");
menu.classList.toggle("abierto");

Esta técnica permite que JavaScript cambie estados mientras CSS decide cómo se visualizan.

12. localStorage

Permite guardar pequeñas cadenas de datos en el navegador. En WebLab se usa únicamente para simular una sesión didáctica.

localStorage.setItem("sesion", "activa");
const sesion = localStorage.getItem("sesion");
localStorage.removeItem("sesion");
Importante: localStorage no debe utilizarse para almacenar contraseñas ni reemplaza una autenticación real con servidor.

13. El carrusel de este proyecto

El Home utiliza un arreglo implícito de elementos seleccionados del DOM, una variable para conocer la posición actual, eventos en botones y clases CSS para mostrar u ocultar diapositivas. Revisa js/home.js e identifica cada concepto.

14. Buenas prácticas

  • Usar const por defecto y let cuando haya reasignación.
  • Nombrar variables y funciones según su propósito.
  • Dividir problemas grandes en funciones pequeñas.
  • No mezclar innecesariamente JavaScript dentro del HTML.
  • Validar entradas y mostrar mensajes comprensibles.
  • No almacenar credenciales reales en JavaScript del navegador.

15. Errores frecuentes

  • Confundir = con comparación.
  • Buscar un elemento con un selector que no existe.
  • Olvidar preventDefault() cuando se quiere validar antes de enviar.
  • Modificar estilos directamente desde JS cuando bastaría con agregar/quitar una clase.
  • Confiar únicamente en validación del navegador para una aplicación real.

Reto JavaScript

Agrega al formulario de clientes validación de nombre, correo y documento. Cuando todo sea válido, muestra un mensaje de éxito sin recargar la página. Como función dinámica adicional, crea un botón que permita mostrar u ocultar un resumen de los datos ingresados.
